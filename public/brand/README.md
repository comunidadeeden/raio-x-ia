# Arquivos oficiais de marca

Substitua os placeholders pelos arquivos oficiais, preservando nomes estáveis quando possível:

- `logo-primary.svg` — logo horizontal principal;
- `symbol-x.svg` — símbolo reduzido;
- `favicon.svg` ou `favicon.png` — ícone do navegador.

O componente `components/brand/brand-mark.tsx` está marcado com `data-brand-placeholder` para facilitar a localização e substituição. O arquivo `app/icon.svg` também é provisório.
